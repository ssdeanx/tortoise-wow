# Blackfathom-Deeps-style roster corrections, as data.
#
# The auto-derived boss roster misses bosses in every dungeon we have measured
# so far, and it has no encounter order at all for most maps. Both used to live
# in DcBossEntries1121.h, so each correction cost a full rebuild. They live
# here now: edit, then `.reload config`. No build.
#
# Two directives, '#' starts a comment:
#
#     credit <entry> [<entry> ...]     add creature entries to the credit list
#     order  <mapId> <entry> <index>   place an entry in that map's order
#
# An `order` line credits its entry as well, so a boss the curated list never
# carried needs the order line and nothing else.
#
# `index` is 1-based and must stay within 1..32 - the completion mask bit is
# index-1. Order is replaced PER MAP: naming any order for a map drops that
# map's compiled rows outright, so what is written here is what runs, never a
# half-merge with a stale compiled order.
#
# Rares are not objectives. A rare that may simply not be in the instance
# (Bruegal Ironknuckle in The Stockade, Lorgus Jett in Blackfathom Deeps) must
# never be given an order line, or every group waits on a spawn that is not
# there.
#
# Worked example - what The Stockade would look like here, were it not already
# compiled in. Two of its five bosses were missing from the credit list, one of
# them Bazil Thredd, the END boss:
#
#     order 34 1696 1      # Targorr the Dread
#     order 34 1663 2      # Dextren Ward
#     order 34 1666 3      # Kam Deepfury
#     order 34 1717 4      # Hamhock
#     order 34 1716 5      # Bazil Thredd (end boss)
#
# Live directives below this line.
